# Project organization

| Top-level directory | What belongs here |
| --- | --- |
| `.github/` | GitHub workflows and the pull request template. |
| `docker/` | Container startup and healthcheck helpers. |
| `deploy/` | Reviewed deployment definitions; AWS resources are not provisioned automatically. |
| `docs/` | Application usage and integration guides. |
| `scripts/` | Development setup and integration smoke-check scripts. |
| `src/` | Python application code and database schemas and migrations. |
| `tests/` | Automated tests, shared test helpers, and provider fixtures. |
